Admins

Admins are stored in admins.json (published via GitHub when a token is set; otherwise kept in this browser only). Passwords are stored only as SHA-256 hashes. The super admin always has every permission and cannot be deleted or demoted.

Settings

GitHub publishing token

Publishing (Add / Edit / Delete posts, syncing admins) writes to the GitHub repo through the Contents API. Paste a fine-grained personal access token below. It is saved only in this browser's local storage (pn_gh_token) and is sent only to api.github.com.

How to create the token

  1. Go to github.com and sign in as the repo owner.
  2. Open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. Click Generate new token and give it a name (e.g. “PickNest Admin Panel”).
  4. Under Repository access, choose Only select repositories → ni-Hridoy/picknest-reviews.
  5. Under Permissions → Repository permissions, set Contents: Read and write.
  6. Click Generate token, copy it, and paste it above.

Draft mode

Without a token, the panel is in draft mode: Add / Edit / Delete are disabled for publishing and nothing is written anywhere. You can still browse posts and admins. Add the token above to enable publishing; every publish is a normal Git commit on main, so Vercel redeploys automatically and the full history stays in GitHub.

Honest note: because this is a static site, the login check runs in the browser and the JSON files are publicly readable. Treat the panel as a convenience tool — the GitHub token is what actually controls who can change the site.
